# SlideCatalog — 研修スライド工房

研修の見本を選び、生成AIに渡す制作指示書を作るツールです。50種類の見本を、表紙と本編3枚で比較できます。

[サイトを開く](https://nullyama.github.io/SlideCatalog/)

## 使い方

1. 目的・タグ・検索から見本を選ぶ。
2. 研修のテーマ、対象者、時間、到達目標を入力する。
3. 指示書をコピーし、ChatGPTなどへ元資料と一緒に渡す。

このサイト自体はスライドやPPTXを生成しません。おすすめの選定はキーワード照合です。

曖昧な希望を相談しながら整理したいときは、[スライド壁打ち・構成設計](skills/plan-slides-dialogue/SKILL.md)を対応するAIに読み込ませて使えます。

研修の構成を詰めたいときは、[日本語研修スライド設計スキル](skills/design-japanese-training/SKILL.md)も使えます。

## 手元で動かす

ダウンロードしたフォルダーで次を実行し、http://localhost:8000 を開きます。ビルドは不要です。

```sh
python -m http.server 8000
```

## データの保存

設定とお気に入りはブラウザ内に保存します。アプリからの外部送信やアクセス解析はありません。機密情報は入力しないでください。外部リンクや生成AIを使う際は、それぞれのサービスの利用条件に従ってください。
