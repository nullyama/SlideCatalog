# SlideCatalog — 研修スライド工房

50種類のオリジナル見本を比較し、生成AIに渡す研修スライド制作指示を作る静的Webアプリです。

## 使い方
1. このリポジトリをダウンロードし、`index.html` をブラウザで開きます。ローカル保存・クリップボード機能が制限される場合はローカルHTTPサーバーで表示してください（例: `python -m http.server 8000`）。
2. 目的・タグ・検索で見本を絞り、表紙＋本編3枚を拡大して選びます。
3. 時間、対象者、学習目標、元資料、演習・評価などを入力します。
4. 制作指示書をコピー／TXT保存し、対応する生成AIに参考資料と見本を添付して作成を依頼します。

## できること・できないこと
- 50件は独自レイアウト見本。外部スキル50件ではありません。外部の制作スキル候補10件は別欄です。
- おすすめはブラウザ内のキーワード判定です。AI API、モデル、バックエンドは組み込んでいません。
- スキルの自動インストール・実行、PPTX自動生成は行いません。
- 入力・お気に入りはブラウザのlocalStorageに保存します。アプリ独自の外部送信・アクセス解析はありません。リンクを開く場合は各サイトへ接続します。
- 初期化で設定を消去できます。機密情報は入力しないでください。生成AIへ送信する資料は組織の規則に従ってください。
- サンプルの数値・組織例は架空です。各候補の4枚すべてが完全に別の設計ではなく、補助レイアウトは共有します。
